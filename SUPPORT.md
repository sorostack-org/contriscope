# Support

## Getting help

- **Documentation** — start with the [README](README.md) and the guides under `docs/`.
- **Issues and bugs** — search the [issue tracker](https://github.com/Sorostack/contriscope/issues)
  before opening a new one.
- **Discussions** — use GitHub
  [discussions](https://github.com/Sorostack/contriscope/discussions) for questions and ideas.

## Before you ask

1. Run `contriscope --help` and check the [README](README.md).
2. Check the [scoring model](docs/SCORING.md) and the [Wave](docs/WAVE.md) /
   [GrantFox](docs/GRANTFOX.md) guides to understand why a score is what it is.
3. Run `contriscope config` to confirm which configuration is in effect.
4. Search existing issues for the same problem.

## Filing a good bug report

Include:

- ContriScope version (`contriscope version`).
- Node.js version (`node --version`).
- The exact command and input used.
- The full output, including any exit code.
- Expected versus actual behavior.

Redact any secrets (Stellar secret keys, tokens) before pasting input.
